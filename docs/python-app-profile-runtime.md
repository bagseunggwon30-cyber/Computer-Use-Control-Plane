# Python app-profile orchestration

`Invoke-MacroAppProfile` uses the fixed `legacy_app_profile.py` entry. Python
owns acquisition sequencing, facade/evaluation budgets, trace checks, explicit
record flags, preflight validation, score and confidence checks, the fixed
history destination and single-append state. The shell supplies the original
record truth as a Boolean fact, preserving its runtime array metadata without
confusing ordinary objects with `value`/`Count` properties for arrays.

The matching C# app-profile facade still computes and validates the recipe.
The retained shell adapter supplies window/CDP/UIA facts and the already
qualified history read/write ports, transports the original shell JSON
semantics to that facade, and renders the final Console output. This cutover
does not make the whole wrapper or standalone owner PowerShell-free.

The history destination and culture arrive in startup arguments. The input
frame accepts only inert `rest` and Boolean `brief`; replies cannot change
startup paths or grant action authority. At most seven acquisitions, seven
facade calls and eight pure evaluations are permitted. Record preflight occurs
before the append; no kernel call follows an attempted append. Failed writes
and disconnected processes are never retried. A parent deadline bounds the
owned worker, and cleanup kills only that worker.

Qualification retains all 496 historical app-profile cases plus the existing
record-boundary and deep/near-limit transport cases. Those compare actual
Console text, JSON, errors, exit codes and acquisition traces to the immutable
historical implementation. Only the three measured durations are normalized.
Additional Python tests reject changed destinations, disabled history, absent
record flags, bad confidence/scores, invalid preflight, unsupported native
actions, cancellation and repeat execution, and cover the fixed entry protocol.

No language exclusions, renamed PowerShell, private CLI source copies, new
unimplemented features or relaxed live-control authorization are used.
