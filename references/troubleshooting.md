# Troubleshooting

Run `cucp doctor --json`. Missing/mismatched workers need explicit publish or a complete matching bundle; there is no rebuild/fallback. Stale observations need fresh observe of exact HWND/PID. Select ambiguous targets; inspect real state after uncertain input. Use privileges for authority diagnostics. Human UAC consent and real GUI acceptance remain required. See [setup](../docs/host-neutral-setup.md) and [migration](../docs/migration-matrix.md). Never publish private desktop captures/logs.
